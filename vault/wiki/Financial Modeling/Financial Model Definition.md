# Financial Model Definition

## Summary

A financial model is defined by three layers: a representation of reality, a calculator, and a tool to build shared conceptual understanding and create business impact. The crucial point is that a model that calculates correctly but is not understood or trusted will not change a decision.

## Key points

- A financial model is defined in three layers: a representation of reality, a calculator, and a tool to build shared conceptual understanding and create business impact.
- A model that calculates correctly but that nobody understands or trusts does not change a decision.
- Newcomers get exposure to modeling.
- Experienced modelers learn to build models that are easier to understand.
- Everyone practices best practices, reasoning by analogy, mental math and ballparking, Excel and AI spreadsheet tools, listening and empathy, and communicating to decision makers.
