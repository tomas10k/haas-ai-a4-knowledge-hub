# Style Guide for Worksheet Tabs

## Summary

This section provides a style guide for worksheet tabs, detailing rules for using decimals based on the quantity being represented. The guide also outlines requirements for page layout and visual hierarchy to ensure clarity in larger models.

## Key points

- No decimals should be used for years and $ in thousands.
- One decimal should be used for most multiples, most percentages, and $ in millions.
- Two decimals should be used for earnings per share, some percentages, and some multiples.
- Print worksheets on one page in landscape orientation.
- Leave row 1 and column A empty as an "entry point."
- Turn off gridlines when printing.
- A title must be placed in the top left of every sheet, with the time period or scenario underneath if relevant.
- Worksheet tabs must be renamed.
- Visual hierarchy should use a limited set of styles for five elements: Worksheet title, Section headers, Section summaries, Worksheet summary, and "Normal" style for everything else.
- An expanded toolkit includes font size 16, light gray fill, navy blue fill, white text on navy, ALL CAPS, and full cell borders, with any consistent combination allowed.
