# Style Guide for Small Sections

## Summary

This style guide curates modeling practices from various sources, primarily investment banking, university, and trade association guides, using the course's design principles to resolve disagreements. It dictates specific rules for structuring calculations, formatting elements, and cell presentation to ensure transparency and clarity.

## Key points

- Calculations should be performed only once and referenced back to it, showing intermediate steps instead of long formulas to ensure transparency.
- Assumptions should not be hard coded inside formulas; separate inputs are recommended for large, reused models.
- Every input and output cell must have a clear, concise label, and acronyms should be avoided.
- Fonts should be consistent across the document, using one font and size between 10 to 12 point.
- Royal blue font is reserved for all constants (inputs), while black font is used for all formulas and text.
- Currency format requires the dollar sign to be shown each time, and thousands separators must always be on.
