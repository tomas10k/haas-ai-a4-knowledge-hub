# AI Tools for Excel

## Summary

AI tools offer various ways to interact with or manipulate Excel data, ranging from general language models to specialized add-ins. These tools can assist with formula help, data cleaning, formatting, and automation depending on the specific tool used.

## Key points

- Basic LLMs like ChatGPT and Gemini involve copying and pasting into a browser chat for formula help, learning concepts, or brainstorming structure.
- Microsoft Copilot features a native Excel sidebar within Microsoft 365 for quick summaries, simple formatting, and PivotTables.
- Shortcut AI is an Excel add-in that reads and writes cells and is best for formula generation, data cleaning, and banking models.
- Claude for Excel is an Excel add-in that reads and writes cells and is suitable for structured formatting and multi-step automation.
- An agentic "fast formatting" workflow involved Claude analyzing design materials and sample spreadsheets to draft instructions encoding a style guide, which were then turned into a reusable skill to reformat a file to the design.
