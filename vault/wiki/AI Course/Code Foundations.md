# Code Foundations

## Summary

This section covers the foundational concepts of code and programming, emphasizing why code literacy is important for business roles, how code executes, the building blocks of programming, common types of errors, best practices for writing clean code, version control with Git/GitHub, local development environments, interaction with AI coding agents, and an example assignment.

## Key points

- Code literacy is important because without it, individuals might ship insecure prototypes, leak API keys, or run experiments against production data instead of a copy.
- Code is described as a recipe with three parts: input, processing, and output, which involves turning fuzzy business policies into exact rules.
- Code execution differs based on language type: interpreted languages like Python and JavaScript are translated line by line, while compiled languages like C, Go, and Rust are translated fully before running.
- The four building blocks of code are variables (holding data types), conditionals (making decisions), loops (repeating work over collections), and functions (packaging reusable logic).
- There are three kinds of errors: Syntax errors (code cannot be read), Runtime errors (code starts then crashes), and Logic errors (code runs but returns a confident wrong answer).
- Clean code principles include prioritizing readability, using descriptive names, named constants, guard clauses, and organizing projects with layers (routers, services, repositories, models).
- Git and GitHub concepts include commits as named, reviewable snapshots, branches for parallel experimentation, diffs showing added/removed lines, and pull requests proposing changes with review conversations.
- Localhost refers to the machine itself (127.0.0.1), and ports are like apartment numbers for network access.
- AI coding agents require checking that their proposed changes match the brief, have no unexpected files, keep secrets in environment variables, pass tests, and can be explained out loud.
- Assignment 1 involved business rules for a discount engine, including specific tiers, overdue invoice handling, and a maximum discount limit.
